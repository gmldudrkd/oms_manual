# Login and Permissions

## Logging In

1. When you go to the OMS web address, the Sign In screen appears.
2. Enter your **company email** and password, then log in.
3. On successful login, you are taken to the [Order Dashboard](../order/dashboard) screen.

:::note Don't have an account?
If you are using the system for the first time, you must first create an account via **Sign Up**. After signing up, you need an administrator's **approval** and **permission grant** before you can see any data.
:::

---

## How to Log In

### User Account Request

1. Click **"Request Account"** at the bottom-right of the login screen.
2. On the **Request Account** page, select the account type and the Brand & Corporation for which you need access, then submit the request.
    - Once approved by an Admin user, you will be able to log in.

<!-- 이미지 추가 예정: Request Account 화면 -->

### Admin Account Approval

1. When a user submits an account request, a Slack notification is sent.
    - The Slack channel is accessible only to users with Admin permissions. (If needed, please request an invitation from the IT team.)
2. Click **"View in OMS."**
    - If an Admin user is logged into OMS, clicking this button will open the approval page. (See image below.)
    - If a user without Admin permission accesses the link, it will display **"No data."**
3. Review the user information and the requested Brand & Corporation, then choose **Approve** or **Reject**.
    - Once the account is approved, an email notification will be sent to the user.

### 2-Factor Authentication Registration

1. After the administrator approves the account, a QR code for generating the **initial** 2-step verification code will appear at first login.
    - **PC**: Install and register using the Google Authenticator extension in the Chrome browser.
        - 🌐 <a href="https://chromewebstore.google.com/detail/authenticator/bhghoamapcdpbohphigoooaddinpkbai" target="_blank" rel="noopener noreferrer">Authenticator - Chrome Web Store</a>
    - **Mobile**: Download and register using the **Microsoft Authenticator** app.
2. After registering the QR code, enter the 6-digit verification code displayed in the authenticator app.
3. For all future logins, enter the 6-digit code generated by the authenticator app.

### Change Password

1. Click **"Forgot Password?"** at the bottom-left of the login screen.
2. Enter your email and submit. A password reset link will be sent to the email you provided.
3. Open the link and enter your new password.

## No permissions means no data appears

If you can log in but the order list is empty, it most likely means you **do not have access permissions yet**. The OMS only shows you data for the **brand × corporation** scope assigned to you.

To obtain permissions, you must submit a **Request Permission** and wait for an administrator's approval. (The request screen and process are explained in detail in [User — Request Permission](../user/request-permission).)

---

## Role Types

Even for the same data, what you can do depends on your **role**. Permissions are granted separately for each brand × corporation combination, so your role may differ by combination — for example, "Manager for GM KR, None for GM JP."

| Role | Display | What you can do (overview) |
|------|-----------|---------------------|
| **Admin** | Blue chip | All operational tasks within the scope + management such as approving user permissions |
| **Manager** | Green chip | General operational processing such as orders, returns, exchanges, and stock |
| **Request** | Orange chip | A permission has been requested and is awaiting approval |
| **None** | Gray chip | No permission (cannot view) |

:::tip
You can check your current permissions by opening your own account in the [User](../user/user-list) list. It shows at a glance which role you hold for each brand and corporation.
:::

## Logging Out

Click the **account menu (person icon + your ID)** in the top-right corner of the screen, then select **"Log out"** to sign out.
